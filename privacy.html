Keine Datenerhebung durch die App

Minh Nguyen Studios erhält über Scrivolo keine Aufnahmen, Transkripte, Projektdateien oder Nutzungsdaten. Es gibt kein Konto, keine Werbung, keine Telemetrie, keine Analyse und keine Cloud.

Lokale Verarbeitung und Speicherung

Die Spracherkennung läuft vollständig auf deinem PC. Projekte, automatische Sicherungen, Einstellungen und ein lokales Fehlerprotokoll liegen im App-Datenordner auf deinem PC. Scrivolo verschlüsselt diese Daten nicht; schütze dein Windows-Konto und deinen Datenträger. Du löschst Projekte und Exporte selbst.

Download der Sprachmodelle

Beim ersten Start lädt Scrivolo auf deinen Wunsch ein Sprachmodell (reine Datendatei, kein Programmcode) von Hugging Face (huggingface.co, Hugging Face Inc., USA) herunter. Dabei übermittelt dein PC technisch notwendig seine IP-Adresse und die Anfrage an diesen Anbieter; es werden keine Aufnahmen oder Inhalte übertragen. Es gilt die Datenschutzerklärung von Hugging Face. Alternativ kannst du eine Modelldatei ohne Internet importieren.

Kauf über den Microsoft Store

Kauf, Bezahlung und Lizenzprüfung der Vollversion laufen über den Microsoft Store. Dafür ist Microsoft verantwortlich; wir erhalten keine Zahlungsdaten. Es gilt die Datenschutzerklärung von Microsoft.

Kontakt per E-Mail

Wenn du uns schreibst, verwenden wir deine Nachricht nur zur Beantwortung (Art. 6 Abs. 1 lit. b bzw. f DSGVO) und löschen sie, wenn sie nicht mehr gebraucht wird. Ein Fehlerprotokoll schickst du nur, wenn du es selbst kopierst und mitsendest.

Diese Website

Die Website wird über GitHub Pages (GitHub Inc., USA) bereitgestellt. GitHub verarbeitet beim Aufruf technisch notwendige Verbindungsdaten wie die IP-Adresse. Wir setzen keine Cookies, keine Tracker und keine externen Skripte ein.

No data collection by the app

Minh Nguyen Studios receives no recordings, transcripts, project files or usage data through Scrivolo. There is no account, no advertising, no telemetry, no analytics and no cloud.

Local processing and storage

Speech recognition runs entirely on your PC. Projects, automatic backups, settings and a local error log are stored in the app data folder on your PC. Scrivolo does not encrypt this data; protect your Windows account and drive. You delete projects and exports yourself.

Speech model download

On first start, at your request, Scrivolo downloads a speech model (a pure data file, no program code) from Hugging Face (huggingface.co, Hugging Face Inc., USA). Your PC necessarily transmits its IP address and the request to this provider; no recordings or content are sent. Hugging Face's privacy policy applies. Alternatively, you can import a model file without internet access.

Purchases via the Microsoft Store

Purchase, payment and licence checks for the full version are handled by the Microsoft Store, for which Microsoft is responsible; we receive no payment data. Microsoft's privacy statement applies.

Contact by email

If you write to us, we use your message only to reply (Art. 6(1)(b) or (f) GDPR) and delete it when no longer needed. You only send an error log if you copy and attach it yourself.

This website

This website is hosted on GitHub Pages (GitHub Inc., USA). GitHub processes technically necessary connection data such as your IP address. We use no cookies, trackers or external scripts.
